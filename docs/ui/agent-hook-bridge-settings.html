Nativer Live-Status für Coding Agents

Platzierung

  • Unter Einstellungen → Coding Agents.
  • Direkt unter der vorhandenen Sichtbarkeitstabelle.
  • Kein ⋯-Menü und keine versteckte Unterseite.

Verhalten

  • Ein sichtbarer Schalter pro unterstütztem, installiertem Agent.
  • Einschalten installiert nur Zaplex-eigene Hooks; Ausschalten entfernt nur diese.
  • Fremde Hook-Einträge und Dateirechte bleiben erhalten.

Zustände

  • Aus, Eingerichtet, Überprüfung nötig, Fehler.
  • Codex gilt erst nach seiner eigenen Hook-Prüfung als aktiv.
  • Antigravity nutzt seinen offiziellen Statuskanal; DeepSeek/CodeWhale dessen lokales Approval-Audit.

Akzeptanz

  • Claude, Codex, Grok, Antigravity und DeepSeek/CodeWhale lassen sich unabhängig schalten.
  • Jede Aktion und jeder Zustand hat ein sichtbares Textlabel.
  • Die UI behauptet nie „aktiv“, wenn nur eine Datei vorhanden ist.
  • Kein Prompt- oder Tool-Inhalt verlässt den lokalen Prozess.
