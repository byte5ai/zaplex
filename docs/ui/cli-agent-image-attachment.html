UI-Spezifikation — Bildanlage im CLI-Agent-Composer

Owner-Entscheidung

  • Das tatsächliche Bild ist als Thumbnail sichtbar.
  • Kein temporärer Dateipfad erscheint im Eingabetext.

Layout

  • 40×40 px Vorschau, Dateiname und sichtbare Entfernen-Aktion.
  • Mehrere Anlagen umbrechen oberhalb des Textfelds.

Verhalten

  • Einfügen erzeugt eine Anlage und verändert den Text nicht.
  • Entfernen löscht genau diese Anlage.
  • Absenden leert Anlagen und übergibt Bilder vor dem Text nativ an den Agent.

Akzeptanz

  • Vorschau zeigt den Bildinhalt, nicht nur ein generisches Icon.
  • Limits entsprechen den bestehenden Bildanlagen.
  • Text-only bleibt unverändert.
