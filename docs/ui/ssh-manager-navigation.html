UI-Spezifikation — Navigation zur Hostverwaltung

Hierarchie

  • „Verbindungen“ ist der primäre Navigationskontext.
  • Das Zahnrad öffnet die Hostverwaltung als genau eine Drill-in-Ebene.
  • Die Hostverwaltung ist bei aktivem Cockpit kein paralleler Toolbelt-Root.

Rückweg

  • Der Header zeigt sichtbar ← Verbindungen.
  • Der Rückweg funktioniert auch nach Schließen/Öffnen und Zustandswiederherstellung.
  • Das × schließt das Panel und ersetzt niemals „Zurück“.

Abnahme

  • Zahnrad → Hostverwaltung → „Verbindungen“ benötigt je einen offensichtlichen Klick.
  • Bei deaktiviertem Cockpit ist die Hostverwaltung primär und zeigt keinen falschen Rückweg.
  • Es existieren höchstens zwei Navigationsebenen.
