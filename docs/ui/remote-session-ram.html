UI-Spezifikation — Remote-Session-RAM

Platzierung

  • Im aufgeklappten Hostblock direkt über den laufenden Sessions.
  • Pro Session bleibt die RAM-Zahl rechtsbündig in derselben Zeile.

Daten

  • Summe ausschließlich aus den vom Daemon gemeldeten Ring-Bytes bilden.
  • Den Host-Cap ausschließlich aus der SessionList des Daemons lesen; niemals clientseitig raten.

Zustände

  • Unter 80 % ruhig im Akzentton, ab 80 % amber, ab 100 % rot.
  • Alte Daemons mit Cap 0 zeigen weiter Sitzungswerte, aber keinen erfundenen Gesamt-Cap.
  • 0 Bytes pro Session bleibt verborgen.

Abnahme

  • Anzeige lautet semantisch „Host-RAM: genutzt / Cap“ und ist nicht nur farbcodiert.
  • Die Summe aktualisiert sich mit jedem erneuten Session-Abruf.
  • Adoptieren und Tastaturfokus der Sessionzeilen bleiben unverändert.
