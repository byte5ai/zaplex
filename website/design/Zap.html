[ HOW ]

How Zap handles every prompt.

每一次对话,Zap 是这样处理的.

Zap keeps the upstream Warp UI — Blocks, Workflows, command suggestions — and replaces static model assumptions with explicit Claude Code and Codex subscription sessions.

Zap 完整保留上游 Warp 的 Blocks / Workflows / 命令建议,并使用显式的 Claude Code 与 Codex 订阅会话。

3 stages 3 阶段
STAGE 01
Captures your block
捕获你的 Block
Each command becomes a Block with its cwd, env, exit code — the full unit of context.
每条命令封装成 Block,带上 cwd / 环境 / 退出码 ── 完整的上下文单元。
STAGE 02
Starts your subscription agent
启动你的订阅 Agent
Choose a signed-in Claude Code or Codex account and one of the models reported by that installation.
选择已登录的 Claude Code 或 Codex 账号，以及该安装 报告的模型。
STAGE 03
Streams back into Blocks
流式回写到 Block
SSE tokens land in the same Block UI you already know. Tools execute locally and re-enter the loop.
SSE token 流式回到熟悉的 Block UI,工具在本地执行后重新回到循环。

Use the subscription agent you trust.

使用你信任的订阅 Agent.

Claude Code and Codex accounts, with models discovered from the installed CLI.

Claude Code 与 Codex 账号，模型由已安装的 CLI 动态提供。

[ 03 / 04 ]

A first-class SSH manager.

一等公民的 SSH 管理.

Net-new in Zap on top of upstream Warp. Saved hosts, jump-host chains, Block-aware remote sessions — all backed by your existing ~/.ssh.

Zap 在上游基础上新增的能力。保存主机、跳板链、Block 感知的远端会话 ── 全部沿用你现有的 ~/.ssh。

net-new 本仓新增
01
Saved hosts
主机收藏
Pin frequent hosts. Connect with one keystroke.
收藏常用主机,一次按键即连接。
02
Jump chains
跳板链
Multi-hop routing through a bastion declared in ssh.toml.
通过 ssh.toml 声明的多跳路由。
03
Block-aware remote
Block 感知远端
Remote sessions render as Blocks — same UX as local.
远端会话同样以 Block 呈现,体验一致。
04
Keys stay home
密钥不离开本机
Existing ~/.ssh reused. ssh.toml holds metadata only.
沿用你的 ~/.ssh,ssh.toml 只保存元数据。

Standing on shoulders.

站在前人肩上.

Zap 是 Warp 的社区 fork。终端的好用之处大多由上游 Warp 与开源生态构建,我们做的事是把 AI 层打开。

[ FAQ ]

Frequently asked.

常见问题.

Is this affiliated with Warp Inc.?这是 Warp 官方的吗?+
No. Zap is a derivative product built on Warp. We are not affiliated with, endorsed by, or sponsored by Warp Inc. The trademarks belong to their respective owners.
不是。Zap 是基于 Warp 构建的衍生产品,与 Warp Inc. 无任何隶属、背书或赞助关系。商标归各自所有者持有。
Can I use my company's private model?能接公司内部的私有模型吗?+
Not through the in-app agent. It intentionally uses signed-in Claude Code or Codex subscriptions only.
内置 Agent 不支持。它只使用已登录的 Claude Code 或 Codex 订阅。
What's different from upstream Warp?和上游 Warp 有什么差别?+
The in-app agent uses signed-in Claude Code or Codex subscriptions with dynamically reported accounts, models, and sessions. Zap also adds its SSH manager and keeps prompts editable.
内置 Agent 使用已登录的 Claude Code 或 Codex 订阅，账号、模型与会话都由 Agent 动态提供。Zap 还增加了 SSH 管理器，并保留可编辑提示词。
Is it production-ready?能上生产吗?+
Not yet. v0.x — expect breaking changes, rough edges, and thin docs. File issues, send PRs.
暂时不行。v0.x 阶段会有 breaking change、粗糙之处、文档不全。欢迎提 issue 与 PR。
License?许可证?+

Source-available,沿用上游 Warp 的许可条款。商业重分发可能需要单独协议 ── 详见 LICENSE.md。
