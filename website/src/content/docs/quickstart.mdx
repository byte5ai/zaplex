## 1. Check the release status

Use the [Zaplex README](https://github.com/byte5ai/zaplex#install) for the current source and release status.
The version prepared by the source tree is not proof that its installer has been published.
Open [Zaplex Releases](https://github.com/byte5ai/zaplex/releases) and download an artifact only when the matching release is available.

## 2. Install and connect

Follow the [Zaplex installation and recovery guide](https://github.com/byte5ai/zaplex/blob/main/docs/release/1.0-user-guide.md) for the supported macOS installation,
SSH host setup, host-key confirmation, and recovery of existing sessions.
The release workflow builds and signs the app and provides the matching Linux host daemon;
the client handles installing that service on a connected host.

## 3. Connect a subscription agent

Install Claude Code or Codex on the machine where the agent should run and complete sign-in in that CLI.
Zaplex discovers the signed-in accounts and the models reported by each installation.
Choose the agent, account, host, directory, and reported model in the Agent target selector.
Local and SSH sessions use the same subscription-only flow; no provider API key or custom endpoint is configured in Zaplex.

The older Zap build commands in the archived visual designs are historical examples, not installation instructions for Zaplex.
